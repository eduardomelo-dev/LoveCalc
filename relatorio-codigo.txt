=== README.md ===
# LoveCalc

Calculadora didática de **Cálculo Diferencial e Integral**, com tema "Doce Amor". Projeto do 1º período de
Engenharia de Software.

![Calculadora no tema escuro, aba Derivadas](frontend/docs/preview.png)

## Estrutura

| Pasta | O que é | Situação |
|---|---|---|
| [`frontend/`](frontend/) | A calculadora: HTML, CSS e JavaScript puros, com testes | ✅ pronta |
| [`backend/`](backend/) | API que vai fazer as contas | ⏳ ainda não existe; o contrato da API está no README da pasta |

Enquanto o back-end não existe, o front-end calcula tudo localmente (`frontend/js/math.js`) e funciona sozinho.

## Rodar o front-end

```bash
cd frontend
python -m http.server 4173   # depois abra http://localhost:4173
npm test                     # 20 testes
```

## Módulos

- **Funções**: constante, afim, quadrática, modular e exponencial, com domínio, imagem, tabela e gráfico.
- **Limites**: removível (0/0), lateral que não existe e no infinito, com tabela de aproximação.
- **Derivadas**: constante, potência, soma, produto, quociente e cadeia, com reta tangente e conferência numérica.
- **Integrais**: cinco regras de primitiva e uma integral definida, com área no gráfico e conferência por Simpson.

## Licença

[MIT](LICENSE). O Three.js incluído em `frontend/vendor/` também é MIT (licença na mesma pasta).

# LoveCalc — back-end (ainda não existe)

Esta pasta está reservada para o back-end. Hoje o front-end faz todas as contas sozinho, em
[`frontend/js/math.js`](../frontend/js/math.js). O back-end vai assumir essa parte. Este documento é o
**contrato** que o front-end espera: com ele, os dois lados podem ser feitos em paralelo.

A linguagem e o framework ficam a critério de quem desenvolver (por exemplo, Node + Express ou Python + FastAPI).

## Regras gerais

- Base: `/api`. Requisições e respostas em JSON (`Content-Type: application/json`), números em ponto decimal (`2.5`).
- Entradas numéricas aceitas: de **−1000 a 1000** (o mesmo limite do front-end).
- Erro de validação: **HTTP 400** com `{ "erro": "mensagem em português para mostrar ao usuário" }`.
- Ponto onde a conta não existe (ex.: divisão por zero): **HTTP 422** com `{ "erro": "..." }`.
- Liberar CORS para o endereço do front-end (em desenvolvimento, `http://localhost:4173`).
- Valores infinitos: mandar `null` e explicar no campo de texto.

## Rotas

### `GET /api/saude`
Para o front-end saber se a API está no ar. Resposta: `{ "ok": true }`.

### `POST /api/funcoes/calcular`
Entrada: `{ "tipo": "quadratic", "x": 10 }`, em que `tipo` é um de `constant`, `linear`, `quadratic`, `absolute` ou `exponential`.

| tipo | função |
|---|---|
| `constant` | C(x) = 55 |
| `linear` | A(x) = 40 + 3x |
| `quadratic` | Q(x) = −0,04(x − 50)² + 100 |
| `absolute` | M(x) = 100 − 2\|x − 50\| |
| `exponential` | E(x) = 100(1 − e^(−0,12x)) |

Resposta:
```json
{
  "y": 36,
  "tabela": [{ "x": 8, "y": 29.44 }, { "x": 9, "y": 32.76 }, { "x": 10, "y": 36 }, { "x": 11, "y": 39.16 }, { "x": 12, "y": 42.24 }],
  "dominio": "ℝ (todos os reais)",
  "imagem": "(−∞, 100]",
  "explicacao": "Parábola com concavidade para baixo: o máximo é 100, no vértice x = 50."
}
```
A `tabela` traz x − 2 até x + 2, de 1 em 1.

### `POST /api/limites/calcular`
Entrada: `{ "caso": "removivel", "a": 5 }`, em que `caso` é um de `removivel`, `lateral` ou `infinito`. O `a` só vale para `removivel`.

| caso | limite |
|---|---|
| `removivel` | lim x→a (x² − a²)/(x − a) = 2a |
| `lateral` | lim x→0 \|x\|/x (não existe: −1 pela esquerda, 1 pela direita) |
| `infinito` | lim x→∞ (3x² + 1)/(x² + 2) = 3 |

Resposta:
```json
{
  "existe": true,
  "valor": 10,
  "esquerda": [{ "x": 4.9, "y": 9.9 }, { "x": 4.99, "y": 9.99 }, { "x": 4.999, "y": 9.999 }],
  "direita": [{ "x": 5.1, "y": 10.1 }, { "x": 5.01, "y": 10.01 }, { "x": 5.001, "y": 10.001 }],
  "passos": ["Em x = 5 a fração vira 0/0: indeterminada.", "Fatore: …", "Simplifique …"]
}
```
Se o limite não existe: `"existe": false, "valor": null`. No caso `infinito`, `esquerda` traz x = 10, 100 e 1000, e `direita` vem vazia.

### `POST /api/derivadas/calcular`
Entrada: `{ "regra": "potencia", "x0": 1 }`, em que `regra` é uma de `constante`, `potencia`, `soma`, `produto`, `quociente` ou `cadeia`.

| regra | f(x) | f′(x) |
|---|---|---|
| `constante` | 55 | 0 |
| `potencia` | x³ | 3x² |
| `soma` | 2x³ − 5x + 10 | 6x² − 5 |
| `produto` | x²(x + 3) | 2x(x + 3) + x² |
| `quociente` | (x² + 1)/(x + 2) | (x² + 4x − 1)/(x + 2)² |
| `cadeia` | 100(1 − e^(−0,12x)) | 12e^(−0,12x) |

Resposta:
```json
{ "y0": 1, "inclinacao": 3, "numerica": 3.00000001, "tangente": { "m": 3, "b": -2 } }
```
`numerica` é a conferência por diferença central com h = 0,0001. A tangente é `y = m·x + b`.
No `quociente` com x0 = −2, responder **422** (o denominador zera).

### `POST /api/integrais/calcular`
Entrada: `{ "tipo": "definida", "a": 0, "b": 7 }`, em que `tipo` é um de `constante`, `potencia`, `soma`, `exponencial`, `trigonometrica` ou `definida`.

| tipo | f(x) | primitiva F(x) |
|---|---|---|
| `constante` | 15 | 15x |
| `potencia` | x³ | x⁴/4 |
| `soma` | 3x² − 2x + 5 | x³ − x² + 5x |
| `exponencial` | e^(0,12x) | e^(0,12x)/0,12 |
| `trigonometrica` | cos(x) | sen(x) |
| `definida` | 50 + 20·sen(πx/7) | 50x − (140/π)·cos(πx/7) |

Resposta:
```json
{ "valor": 439.1268, "numerica": 439.1268, "Fa": -44.5634, "Fb": 394.5634 }
```
`valor` = F(b) − F(a); `numerica` é a conferência pela regra de Simpson com n = 200. Se a = b, o valor é 0.

## Como o front-end vai trocar para a API

1. Criar `frontend/js/api.js` com uma função por rota (`fetch` + tratamento de erro).
2. Em `frontend/js/app.js`, trocar as chamadas de `calculateFunction`/`tabelaFuncao`, `LIMITES[caso].calcular`,
   `calcularDerivada` e `calcularIntegral` pelas funções do `api.js`.
3. Manter `math.js` como reserva: se `GET /api/saude` falhar, a calculadora continua funcionando offline.
4. Os textos das fórmulas e as funções usadas para desenhar o gráfico continuam no front-end.

Os testes de `frontend/tests/math.test.js` servem de referência para os testes do back-end: os mesmos
números de entrada devem dar os mesmos resultados.

// POST /api/derivadas/calcular  { "regra": "potencia", "x0": 1 }
import { Router } from "express";

import { DERIVADAS, calcularDerivada } from "../calculos/derivadas.js";
import { lerCorpo, lerNumero, lerOpcao } from "../validacao.js";

const rotas = Router();

rotas.post("/calcular", (req, res) => {
  const corpo = lerCorpo(req);
  const regra = lerOpcao(corpo.regra, "regra", DERIVADAS);
  const x0 = lerNumero(corpo.x0, "x0");
  res.json(calcularDerivada(regra, x0));
});

export default rotas;

# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

O grupo da disciplina de Cálculo Diferencial e Integral (Engenharia de Software, UniCatólica-RN) apresenta a calculadora em sala, projetada num telão a partir de um notebook, para a professora avaliar. Quem opera é um integrante do grupo; quem lê é a turma e a professora, à distância.

## Product Purpose

Calculadora didática de CDI com quatro módulos executáveis: Funções (5 tipos, com domínio, imagem, tabela e gráfico), Limites (removível e inexistente, com limites laterais), Derivadas (6 regras) e Integrais (5 regras indefinidas + 1 definida). Cada módulo mostra a fórmula, os valores usados, o resultado e uma explicação curta. O sucesso é a professora conseguir conferir cada cálculo na tela e o grupo demonstrar os quatro módulos sem rolar página nem se perder.

## Positioning

É uma calculadora, não um site: uma tela só, com abas que alternam os módulos. Os resultados são calculados de verdade a partir das entradas (não são textos fixos).

## Constraints

- Somente front-end (HTML, CSS e JavaScript puro, sem dependências); o back-end será feito por outra pessoa e poderá substituir `js/math.js` por chamadas `fetch`.
- Deve caber numa tela de notebook projetada (sem rolagem da página no desktop), com texto legível de longe.
- Entradas validadas (vazias, fora do intervalo, divisão por zero).
- Entrega exige testes (`npm test`), documentação, histórico de commits e registro dos prompts de IA.
- Tema Doce Amor só como identidade discreta (nome e cores); sem artes do jogo, sem tela de compatibilidade de nomes (decisão do grupo, 2026-11-17).
- Animação de cursores 3D montando os blocos ao trocar de aba, só no desktop, sem bloquear cliques. Ligada por padrão mesmo com os efeitos de animação do Windows desligados (o notebook do dono tem esse ajuste); um botão "Animações" na barra liga e desliga todas as animações (cursores, gráfico, visor) e lembra a escolha.

## Voice

pt-BR, direto e didático: frases curtas que explicam o passo do cálculo.


=== frontend\README.md ===
# LoveCalc — front-end

Calculadora didática de Cálculo Diferencial e Integral, numa tela só com quatro abas: **Funções**, **Limites**,
**Derivadas** e **Integrais**. Feita em HTML, CSS e JavaScript puros, sem dependências e sem internet
(o Three.js dos cursores animados fica copiado em `vendor/`).

![Calculadora no tema escuro, aba Derivadas](docs/preview.png)

## Como rodar

Os módulos JavaScript precisam de um servidor local (abrir o `index.html` direto não funciona):

```bash
cd frontend
python -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Testes

```bash
cd frontend
npm test
```

São 20 testes (`node --test`): contas de `math.js`, desenho do gráfico e trajetórias dos cursores.

## O que tem na tela

- **Controles** (esquerda): escolha do tipo, da regra ou do caso, e os valores de entrada, com validação.
- **Visor**: expressão, resultado e explicação curta. No canto, uma **dica** do assunto da aba ("Outra dica ›" troca).
- **Gráfico**: plano cartesiano próprio em canvas, com tangente, área, buraco e as cenas didáticas
  (pontos se aproximando no limite, secante virando tangente, retângulos de Riemann). Dá para arrastar o ponto e as bordas.
- **Como foi calculado** (direita): passos, valores e conferência numérica.
- **Animações**: setas que montam a tela ao trocar de aba. O botão "Animações" liga e desliga tudo.
- Atalhos: teclas 1–4 trocam de aba.

## Estrutura

```
index.html             tela única (abas, controles, visor, gráfico, detalhes)
styles.css             tema escuro "Doce Amor" (cores nomeadas no :root)
js/app.js              interface: abas, validação, visor, gráfico, dicas
js/math.js             contas (puras, sem DOM) — o back-end vai substituir por chamadas à API
js/graph.js            desenho do plano cartesiano (canvas 2D)
js/dicas.js            dicas de cada aba
js/cursor-*.js         cursores animados (Three.js)
assets/marca/          logo e símbolo em SVG
docs/                  guia de identidade visual e imagem de prévia
tests/                 testes com node --test
```

estão em [`docs/identidade-visual.html`](docs/identidade-visual.html) (abra pelo servidor local).

function mostrarValor(R, anterior, arrastando = false) {

    const e = 1 - (1 - suave(c)) ** 2, d = cena.de * (1 - e) + 0.004;
    const xl = cena.alvo - d, xr = cena.alvo + d;
    return { g: { aproximar: [{ x: xl, y: cena.f(xl), lado: "esquerda" }, { x: xr, y: cena.f(xr), lado: "direita" }] }, nota: `x → ${fmt(cena.alvo)}: pela esquerda ${fmt(cena.f(xl), 3)}, pela direita ${fmt(cena.f(xr), 3)}` };
  }
  if (cena.tipo === "infinito") {
    const x = lerp(cena.de, cena.ate, suave(c));
    return { g: { aproximar: [{ x, y: cena.f(x), lado: "direita" }] }, nota: `x = ${fmt(x, 1)}: f(x) = ${fmt(cena.f(x), 3)} → 3` };
  }
  if (cena.tipo === "secante") {
    const e = suave(c / 0.85), h = 2.6 * (1 - e) ** 1.6 + 0.002, fim = Math.max(0, (c - 0.85) / 0.15);
    const m = (cena.f(cena.x0 + h) - cena.f(cena.x0)) / h;
    return { g: { secante: { x0: cena.x0, x1: cena.x0 + h, alfa: 1 - fim }, extras: fim }, nota: `inclinação da secante (h = ${fmt(h, 3)}) = ${fmt(m, 4)} → f′(x₀) = ${fmt(cena.inclinacao, 4)}` };
  }
  if (cena.tipo === "riemann") {
    const NS = [2, 4, 8, 16, 32, 64], k = Math.min(NS.length - 1, Math.floor((c / 0.86) * NS.length)), n = NS[k];
    const dx = (cena.b - cena.a) / n; let soma = 0;
    for (let i = 0; i < n; i += 1) { const y = cena.f(cena.a + (i + 0.5) * dx); if (Number.isFinite(y)) soma += y * dx; }
    const fim = Math.max(0, (c - 0.86) / 0.14);
    return { g: { riemann: { a: cena.a, b: cena.b, n, alfa: 1 - fim }, extras: fim }, nota: `Soma com ${n} retângulos ≈ ${fmt(soma, 4)} (exato: ${fmt(cena.exato, 4)})` };
  }
  return { g: {} };
}

function animarGrafico(anterior, modo) {
  cancelAnimationFrame(quadroGrafico);
  const R = ultimo, novo = R?.grafico, nota = $("#visor-nota");
  const velho = modo === "transformar" || modo === "arrastar" || modo === "cena" ? (graficoAtual ?? anterior?.grafico) : null;
  if (!novo) { graficoAtual = null; const c = $("#grafico"); c.getContext("2d").clearRect(0, 0, c.width, c.height); return; }
  if (!animacoesLigadas()) { graficoAtual = novo; desenhar(); return; }
  const comCena = (modo === "revelar" || modo === "cena") && R.cena;
  const durBase = modo === "revelar" ? 1500 : modo === "arrastar" ? 130 : 900;
  const durCena = comCena ? CENA : 0, total = durBase + durCena + 750;
  const t0 = performance.now();
  const quadro = (agora) => {
    const t = agora - t0, k = durBase ? Math.min(1, t / durBase) : 1, e = 1 - (1 - k) ** 3;
    let g;
    if (velho) {
      const fa = velho.f, fb = novo.f;
      g = {
        ...novo,
        range: misturarRange(velho.range, novo.range, e),
        f: (x) => { const a = fa(x), b = fb(x); return Number.isFinite(a) && Number.isFinite(b) ? lerp(a, b, e) : (e < 0.5 ? a : b); },
        tangent: novo.tangent && velho.tangent ? (x) => lerp(velho.tangent(x), novo.tangent(x), e) : novo.tangent,
        area: novo.area && velho.area ? { a: lerp(velho.area.a, novo.area.a, e), b: lerp(velho.area.b, novo.area.b, e) } : novo.area,
        points: (novo.points ?? []).map((p, i) => { const q = velho.points?.[i]; return q ? { x: lerp(q.x, p.x, e), y: lerp(q.y, p.y, e) } : p; }),
        holes: (novo.holes ?? []).map((p, i) => { const q = velho.holes?.[i]; return q ? { x: lerp(q.x, p.x, e), y: lerp(q.y, p.y, e) } : p; }),
        extras: (novo.tangent && !velho.tangent) || (novo.area && !velho.area) ? e : 1,
      };
    } else if (modo === "revelar") {
      g = { ...novo, revelar: e, extras: comCena ? 0 : Math.max(0, (k - 0.35) / 0.65), ponto: k < 0.62 ? 0 : backOut((k - 0.62) / 0.38) };
    } else g = { ...novo };
    // cena didática depois que a curva já está desenhada
    if (comCena && t >= durBase) {
      const c = Math.min(1, (t - durBase) / durCena), q = quadroCena(R.cena, c);
      Object.assign(g, q.g);
      if (q.nota && R === ultimo) nota.textContent = c < 1 ? q.nota : R.nota;
    }
    if (t > durBase + durCena) g.pulso = Math.min(1, (t - durBase - durCena) / 750);
    graficoAtual = { ...novo };
    desenharQuadro(g);
    if (t < total) quadroGrafico = requestAnimationFrame(quadro);
    else { quadroGrafico = 0; if (R === ultimo) nota.textContent = R.erro ?? R.nota; }
  };
  graficoAtual = null;
  quadroGrafico = requestAnimationFrame(quadro);
}

// Cursores (setas comuns desenhadas com Three.js, cópia local em /vendor) que montam os blocos da aba.
// O movimento é calculado a cada quadro (requestAnimationFrame) por arcos de Bézier
// com suavização e um "clique" que afunda o cursor de leve.
// Nunca bloqueia: a camada não recebe cliques e qualquer tecla/clique termina a montagem.
import * as THREE from "../vendor/three.module.min.js";
import { canPlayCursorOrchestra, planRoutes, bezier, arcControls, travelTime, easeInOutCubic } from "./cursor-path.js";

const PEGAR = 0.35, SOLTAR = 0.35, PAUSA = 0.3;

// Preferência explícita da pessoa (botão "Animações"). Padrão: ligado, mesmo com os
// efeitos de animação do sistema desligados, porque as animações fazem parte da apresentação.
const CHAVE = "doce-amor:animacoes";
export function animacoesLigadas() {
  try { return localStorage.getItem(CHAVE) !== "off"; } catch { return true; }
}
export function definirAnimacoes(ligado) {
  try { localStorage.setItem(CHAVE, ligado ? "on" : "off"); } catch { /* sem armazenamento: vale só nesta aba */ }
}

export function cursorsAllowed() {
  return canPlayCursorOrchestra({
    reducedMotion: !animacoesLigadas(),
    finePointer: matchMedia("(pointer: fine)").matches,
    compactViewport: matchMedia("(max-width: 900px)").matches,
  });
}

export class CursorOrchestra {
  constructor() {
    this.ativo = null;
    this.canvas = null;
  }

  #montarCena() {
    if (this.renderer) return true;
    try {
      this.canvas = document.createElement("canvas");
      this.canvas.className = "cursor-layer";
      this.canvas.setAttribute("aria-hidden", "true");
      document.body.append(this.canvas);
      this.renderer = new THREE.WebGLRenderer({ canvas: this.canvas, alpha: true, antialias: true });
    } catch {
      this.canvas?.remove(); this.canvas = null; return false;
    }
    this.renderer.setPixelRatio(Math.min(devicePixelRatio || 1, 2));
    this.cena = new THREE.Scene();
    this.camera = new THREE.OrthographicCamera(0, 1, 0, -1, -500, 500);
    const geo = new THREE.ShapeGeometry(setaForma());
    const borda = new THREE.BufferGeometry().setFromPoints([...SETA, SETA[0]].map(([x, y]) => new THREE.Vector3(x, y, 1)));
    const corpoMat = new THREE.MeshBasicMaterial({ color: 0xffffff });
    const bordaMat = new THREE.LineBasicMaterial({ color: 0x000000 });
    this.cursores = [1, 2, 3, 4].map(() => {
      const seta = new THREE.Group();
      seta.add(new THREE.Mesh(geo, corpoMat), new THREE.Line(borda, bordaMat));
      seta.visible = false;
      this.cena.add(seta);
      return { seta };
    });
    return true;
  }

  #ajustarTamanho() {
    const W = innerWidth, H = innerHeight;
    this.renderer.setSize(W, H, false);
    Object.assign(this.camera, { left: 0, right: W, top: 0, bottom: -H });
    this.camera.updateProjectionMatrix();
  }

  /** Monta os blocos: cada cursor busca um bloco na lateral da tela e o arrasta até o lugar.
   *  Sem WebGL ou sem permissão: só um surgimento curto. */
  play(pecas) {
    this.terminar();
    if (!pecas.length) return;
    pecas.forEach((p) => p.classList.add("peca-pendente"));
    if (!cursorsAllowed() || !this.#montarCena()) {
      pecas.forEach((p, i) => this.#revelar(p, null, i * 110));
      return;
    }
    this.#ajustarTamanho();
    const W = innerWidth;
    // para cada bloco: de que lado vem, onde a seta segura (ponto da borda que entra primeiro)
    // e onde a pega começa (perto da borda da tela, com o bloco quase todo de fora)
    const pegas = pecas.map((p, i) => {
      const r = p.getBoundingClientRect(), cx = r.left + r.width / 2;
      const esquerda = cx < W * 0.45 ? true : cx > W * 0.55 ? false : i % 2 === 0;
      const y = r.top + Math.min(r.height * 0.3, 60);
      const segura = { x: esquerda ? r.right - 34 : r.left + 34, y };
      const comeco = { x: esquerda ? 60 : W - 60, y };
      return { esquerda, segura, comeco, chegada: { x: esquerda ? -40 : W + 40, y: y + 90 } };
    });

    const roteiros = planRoutes(pecas.length, this.cursores.length).map((rota, c) => {
      const passos = []; let t = c * 0.55, de = pegas[rota[0]].chegada;
      rota.forEach((i) => {
        const { comeco, segura, esquerda } = pegas[i];
        const dur = travelTime(de, comeco), [c1, c2] = arcControls(de, comeco, esquerda ? 1 : -1, 0.2);
        passos.push({ tipo: "voo", t0: t, t1: t + dur, de, c1, c2, para: comeco });
        t += dur;
        passos.push({ tipo: "pegar", t0: t, t1: t + PEGAR, em: comeco, peca: i, segura });
        t += PEGAR;
        const arr = Math.min(2, Math.max(1.2, Math.abs(segura.x - comeco.x) / 550));
        const [a1, a2] = arcControls(comeco, segura, esquerda ? -1 : 1, 0.04);
        passos.push({ tipo: "arrastar", t0: t, t1: t + arr, de: comeco, c1: a1, c2: a2, para: segura, peca: i, segura });
        t += arr;
        passos.push({ tipo: "soltar", t0: t, t1: t + SOLTAR, em: segura, peca: i });
        t += SOLTAR + PAUSA; de = segura;
      });
      const ultima = pegas[rota.at(-1)], fim = { x: ultima.esquerda ? -60 : W + 60, y: ultima.segura.y + 160 };
      const dur = travelTime(de, fim), [c1, c2] = arcControls(de, fim, ultima.esquerda ? -1 : 1, 0.18);
      passos.push({ tipo: "voo", t0: t, t1: t + dur, de, c1, c2, para: fim, saida: true });
      return passos;
    });
    const total = Math.max(...roteiros.map((r) => r.at(-1).t1));
    this.canvas.classList.add("ativa");
    document.documentElement.classList.add("montando");

    const inicio = performance.now();
    const pular = () => this.terminar();
    addEventListener("pointerdown", pular, { once: true, capture: true });
    addEventListener("keydown", pular, { once: true, capture: true });
    addEventListener("wheel", pular, { once: true, passive: true });
    addEventListener("resize", pular, { once: true });
    this.ativo = { pecas, quadro: 0, pular };

    const quadro = (agora) => {
      if (!this.ativo) return;
      const t = (agora - inicio) / 1000;
      roteiros.forEach((r, c) => this.#posar(this.cursores[c], r, t, pecas));
      this.renderer.render(this.cena, this.camera);
      if (t < total + 0.3) this.ativo.quadro = requestAnimationFrame(quadro);
      else this.terminar();
    };
    this.ativo.quadro = requestAnimationFrame(quadro);
  }

  #posar(cu, roteiro, t, pecas) {
    const passo = roteiro.find((p) => t < p.t1) ?? roteiro.at(-1);
    if (t < roteiro[0].t0) { cu.seta.visible = false; return; }
    cu.seta.visible = true;
    const k = Math.min(1, Math.max(0, (t - passo.t0) / (passo.t1 - passo.t0)));
    let pos, pressao = 0;
    if (passo.tipo === "voo") {
      pos = bezier(passo.de, passo.c1, passo.c2, passo.para, easeInOutCubic(k));
      if (passo.saida && k >= 1) cu.seta.visible = false;
    } else if (passo.tipo === "pegar") {
      pos = passo.em; pressao = easeInOutCubic(k);
      // o bloco espia na borda, com a ponta presa na seta
      arrastarPeca(pecas[passo.peca], pos.x - passo.segura.x, pos.y - passo.segura.y, 0.25 * k);
    } else if (passo.tipo === "arrastar") {
      const e = easeInOutCubic(k);
      pos = bezier(passo.de, passo.c1, passo.c2, passo.para, e); pressao = 1;
      arrastarPeca(pecas[passo.peca], pos.x - passo.segura.x, pos.y - passo.segura.y, 0.25 + 0.75 * e);
    } else {
      pos = passo.em; pressao = 1 - easeInOutCubic(k);
      soltarPeca(pecas[passo.peca]);
    }
    cu.seta.position.set(pos.x, -pos.y, 0);
    cu.seta.scale.setScalar(1 - pressao * 0.12); // segurando: afunda de leve
  }

  #revelar(peca, ponto, atraso) {
    const r = peca.getBoundingClientRect();
    const origem = ponto ? `${ponto.x - r.left}px ${ponto.y - r.top}px` : "50% 0%";
    peca.style.transformOrigin = origem;
    peca.classList.remove("peca-pendente");
    peca.animate(
      [
        { opacity: 0, transform: "translateY(10px) scale(.98)", filter: "blur(4px)" },
        { opacity: 1, offset: 0.55, filter: "blur(0)" },
        { opacity: 1, transform: "none", filter: "blur(0)" },
      ],
      { duration: 1000, delay: atraso, easing: "cubic-bezier(.22,1,.36,1)", fill: "backwards" },
    );
  }

  /** Termina na hora: revela o que faltar e some com os cursores. */
  terminar() {
    const a = this.ativo; this.ativo = null;
    if (!a) return;
    cancelAnimationFrame(a.quadro);
    removeEventListener("pointerdown", a.pular, { capture: true });
    removeEventListener("keydown", a.pular, { capture: true });
    removeEventListener("wheel", a.pular);

/** Curva de Bézier cúbica. */
export function bezier(p0, p1, p2, p3, t) {
  const u = 1 - t;
  return {
    x: u * u * u * p0.x + 3 * u * u * t * p1.x + 3 * u * t * t * p2.x + t * t * t * p3.x,
    y: u * u * u * p0.y + 3 * u * u * t * p1.y + 3 * u * t * t * p2.y + t * t * t * p3.y,
  };
}

/** Pontos de controle de um arco suave de a até b (curva para um lado, como a mão faz). */
export function arcControls(a, b, lado = 1, curvatura = 0.28) {
  const dx = b.x - a.x, dy = b.y - a.y, L = Math.hypot(dx, dy) || 1;
  const nx = (-dy / L) * L * curvatura * lado, ny = (dx / L) * L * curvatura * lado;
  return [{ x: a.x + dx * 0.25 + nx, y: a.y + dy * 0.25 + ny }, { x: a.x + dx * 0.75 + nx * 0.6, y: a.y + dy * 0.75 + ny * 0.6 }];
}

export function travelTime(a, b) {

}

// Plano cartesiano em canvas, sem bibliotecas. Desenha uma função qualquer, com
// extras opcionais: reta tangente, área entre a e b, pontos marcados e buracos.

/** Amostra f no intervalo; pontos não finitos viram null (quebra a linha). */
export function sample(f, xMin, xMax, steps = 240) {
  return Array.from({ length: steps + 1 }, (_, i) => {
    const x = xMin + ((xMax - xMin) * i) / steps;
    const y = f(x);
    return Number.isFinite(y) ? { x, y } : null;
  });
}

/** Intervalo de y que cabe a curva, com folga, e ignora valores absurdos. */
export function autoRange(f, xMin, xMax, extras = []) {
  const ys = sample(f, xMin, xMax, 160).filter(Boolean).map((p) => p.y).concat(extras).filter((y) => Math.abs(y) < 1e6);
  let yMin = Math.min(...ys), yMax = Math.max(...ys);
  if (yMin === yMax) { yMin -= 5; yMax += 5; }
  const pad = (yMax - yMin) * 0.12;
  return { xMin, xMax, yMin: yMin - pad, yMax: yMax + pad };
}

/** Passo "bonito" (1, 2, 5 × 10ⁿ) para a grade. */
export function niceStep(span, alvo = 8) {
  const bruto = span / alvo, p = 10 ** Math.floor(Math.log10(bruto)), m = bruto / p;
  return (m < 1.5 ? 1 : m < 3.5 ? 2 : m < 7.5 ? 5 : 10) * p;
}

/**
 * Desenha o quadro do gráfico. Parâmetros de animação (todos 0..1, padrão 1):
 *   revelar   — fração da largura já desenhada (a curva "se escreve" da esquerda para a direita)
 *   extras    — opacidade da tangente, da área e dos buracos
 *   ponto     — escala do ponto marcado (entra com um pequeno salto)
 *   pulso     — anel que se expande em volta do ponto (0 = sem anel)
 * Cenas didáticas (opcionais):
 *   secante   — { x0, x1, alfa }: reta secante que gira até a tangente quando x1 → x0
 *   aproximar — [{ x, y, lado }]: pontos que correm pela curva até o limite, com o valor ao lado
 *   riemann   — { a, b, n, alfa }: retângulos (ponto médio) que aproximam a área
 *   mira      — { x }: linha e etiqueta (x; f(x)) sob o mouse
 *   alcas     — mostra as alças arrastáveis (ponto e bordas da área)
 */
export function drawGraph(canvas, { f, range, tangent, area, points = [], holes = [], cores, fonte = "system-ui", revelar = 1, extras = 1, ponto = 1, pulso = 0, secante, aproximar, riemann, mira, alcas = false }) {
  const ctx = canvas.getContext("2d");
  const ratio = window.devicePixelRatio || 1;
  const W = canvas.clientWidth, H = canvas.clientHeight;
  if (!W || !H) return;
  const cw = Math.round(W * ratio), ch = Math.round(H * ratio);
  if (canvas.width !== cw || canvas.height !== ch) { canvas.width = cw; canvas.height = ch; }
  ctx.setTransform(ratio, 0, 0, ratio, 0, 0);
  const pad = { t: 18, r: 18, b: 34, l: 52 };
  const w = W - pad.l - pad.r, h = H - pad.t - pad.b;
  const { xMin, xMax, yMin, yMax } = range;
  const X = (x) => pad.l + ((x - xMin) / (xMax - xMin)) * w;
  const Y = (y) => pad.t + h - ((y - yMin) / (yMax - yMin)) * h;
  const base = Y(Math.max(yMin, Math.min(0, yMax)));
  // o app usa este mapa para converter o mouse em x (arrastar e mira)
  canvas.__mapa = { xDe: (px) => xMin + ((px - pad.l) / w) * (xMax - xMin), X, Y, pad, w, h };
  ctx.clearRect(0, 0, W, H);

  // grade e rótulos
  const sx = niceStep(xMax - xMin), sy = niceStep(yMax - yMin, 6);
  ctx.lineWidth = 1; ctx.strokeStyle = cores.grade;
  ctx.font = `500 12px ${fonte}`; ctx.fillStyle = cores.rotulo;
  ctx.textAlign = "center"; ctx.textBaseline = "top";
  for (let x = Math.ceil(xMin / sx) * sx; x <= xMax + 1e-9; x += sx) {
    ctx.beginPath(); ctx.moveTo(X(x), pad.t); ctx.lineTo(X(x), pad.t + h); ctx.stroke();
    ctx.fillText(fmt(x), X(x), pad.t + h + 8);
  }
  ctx.textAlign = "right"; ctx.textBaseline = "middle";
  for (let y = Math.ceil(yMin / sy) * sy; y <= yMax + 1e-9; y += sy) {
    ctx.beginPath(); ctx.moveTo(pad.l, Y(y)); ctx.lineTo(pad.l + w, Y(y)); ctx.stroke();
    ctx.fillText(fmt(y), pad.l - 8, Y(y));
  }

  // eixos
  ctx.strokeStyle = cores.eixo; ctx.lineWidth = 1.5; ctx.beginPath();
  if (yMin <= 0 && yMax >= 0) { ctx.moveTo(pad.l, Y(0)); ctx.lineTo(pad.l + w, Y(0)); }
  if (xMin <= 0 && xMax >= 0) { ctx.moveTo(X(0), pad.t); ctx.lineTo(X(0), pad.t + h); }
  ctx.stroke();

  // tudo o que é "conteúdo" fica recortado na área do gráfico e na fração já revelada
  ctx.save(); ctx.beginPath(); ctx.rect(pad.l, pad.t - 4, w * revelar, h + 8); ctx.clip();

  // área (integral definida): degradê da curva até o eixo
  if (area && extras > 0) {
    const a = Math.max(area.a, xMin), b = Math.min(area.b, xMax);
    const pts = sample(f, a, b, 160).filter(Boolean);
    const g = ctx.createLinearGradient(0, pad.t, 0, pad.t + h);
    g.addColorStop(0, cores.areaForte); g.addColorStop(1, cores.area);
    ctx.globalAlpha = extras;
    ctx.beginPath(); ctx.moveTo(X(a), base);
    pts.forEach((p) => ctx.lineTo(X(p.x), Y(p.y)));
    ctx.lineTo(X(b), base); ctx.closePath();
    ctx.fillStyle = g; ctx.fill();
    ctx.strokeStyle = cores.curva; ctx.lineWidth = 1; ctx.setLineDash([3, 4]);
    ctx.beginPath(); ctx.moveTo(X(a), base); ctx.lineTo(X(a), Y(f(a))); ctx.moveTo(X(b), base); ctx.lineTo(X(b), Y(f(b))); ctx.stroke();
    ctx.setLineDash([]); ctx.globalAlpha = 1;
  }

  if (riemann && riemann.alfa > 0) {
    const { a, b, n } = riemann, dx = (b - a) / n;
    ctx.globalAlpha = riemann.alfa;
    for (let i = 0; i < n; i += 1) {
      const xm = a + (i + 0.5) * dx, y = f(xm);
      if (!Number.isFinite(y)) continue;
      const x1 = X(a + i * dx), x2 = X(a + (i + 1) * dx), yy = Y(y);
      ctx.fillStyle = i % 2 ? cores.retangulo2 : cores.retangulo;
      ctx.fillRect(x1, Math.min(yy, base), x2 - x1, Math.abs(base - yy));
      if (n <= 32) { ctx.strokeStyle = cores.fundo; ctx.lineWidth = 1; ctx.strokeRect(x1, Math.min(yy, base), x2 - x1, Math.abs(base - yy)); }
    }
    ctx.globalAlpha = 1;
  }

  // curva (quebra em pontos inválidos e em saltos verticais), com um brilho suave por baixo
  const tracar = () => {
    ctx.beginPath(); let prev = null;
    for (const p of sample(f, xMin, xMax)) {
      if (!p) { prev = null; continue; }
      const salto = prev && Math.abs(Y(p.y) - Y(prev.y)) > h * 0.8;
      if (!prev || salto) ctx.moveTo(X(p.x), Y(p.y)); else ctx.lineTo(X(p.x), Y(p.y));
      prev = p;
    }
  };
  ctx.lineJoin = "round"; ctx.lineCap = "round";
  ctx.strokeStyle = cores.brilho; ctx.lineWidth = 10; tracar(); ctx.stroke();
  ctx.strokeStyle = cores.curva; ctx.lineWidth = 3.2; tracar(); ctx.stroke();

  if (tangent && extras > 0) {
    ctx.globalAlpha = extras;
    ctx.strokeStyle = cores.tangente; ctx.lineWidth = 2.2; ctx.setLineDash([8, 6]);
    ctx.beginPath(); ctx.moveTo(X(xMin), Y(tangent(xMin))); ctx.lineTo(X(xMax), Y(tangent(xMax))); ctx.stroke();
    ctx.setLineDash([]); ctx.globalAlpha = 1;
  }
  if (secante && secante.alfa > 0) {
    const { x0, x1 } = secante, y0 = f(x0), y1 = f(x1);
    if (Number.isFinite(y0) && Number.isFinite(y1) && x1 !== x0) {
      const m = (y1 - y0) / (x1 - x0), r = (x) => y0 + m * (x - x0);
      ctx.globalAlpha = secante.alfa;
      ctx.strokeStyle = cores.secante; ctx.lineWidth = 2.4;
      ctx.beginPath(); ctx.moveTo(X(xMin), Y(r(xMin))); ctx.lineTo(X(xMax), Y(r(xMax))); ctx.stroke();
      ctx.fillStyle = cores.secante;
      ctx.beginPath(); ctx.arc(X(x1), Y(y1), 5.5, 0, Math.PI * 2); ctx.fill();
      // "h" desenhado como uma cota entre x0 e x1
      const yb = Math.min(pad.t + h - 6, Math.max(Y(y0), Y(y1)) + 22);
      ctx.strokeStyle = cores.secante; ctx.lineWidth = 1.2; ctx.beginPath();
      ctx.moveTo(X(x0), yb - 5); ctx.lineTo(X(x0), yb + 5); ctx.moveTo(X(x1), yb - 5); ctx.lineTo(X(x1), yb + 5);
      ctx.moveTo(X(x0), yb); ctx.lineTo(X(x1), yb); ctx.stroke();
      ctx.font = `italic 600 13px ${fonte}`; ctx.textAlign = "center"; ctx.textBaseline = "top";
      ctx.fillText(`h = ${fmt3(x1 - x0)}`, (X(x0) + X(x1)) / 2, yb + 6);
      ctx.globalAlpha = 1;
    }
  }
  ctx.restore();

  for (const p of points) {
    const px = X(p.x), py = Y(p.y);
    if (pulso > 0 && pulso < 1) {
      ctx.beginPath(); ctx.arc(px, py, 7 + pulso * 22, 0, Math.PI * 2);
      ctx.strokeStyle = cores.curva; ctx.globalAlpha = (1 - pulso) * 0.7; ctx.lineWidth = 2; ctx.stroke(); ctx.globalAlpha = 1;
    }
    if (ponto <= 0) continue;
    ctx.beginPath(); ctx.arc(px, py, 7 * ponto, 0, Math.PI * 2);
    ctx.fillStyle = cores.ponto; ctx.fill(); ctx.lineWidth = 3; ctx.strokeStyle = cores.fundo; ctx.stroke();
  }
  ctx.globalAlpha = extras;
  for (const p of holes) {
    ctx.beginPath(); ctx.arc(X(p.x), Y(p.y), 6.5, 0, Math.PI * 2);
    ctx.fillStyle = cores.fundo; ctx.fill(); ctx.lineWidth = 2.6; ctx.strokeStyle = cores.curva; ctx.stroke();
  }
  ctx.globalAlpha = 1;

  for (const a of aproximar ?? []) {
    if (!Number.isFinite(a.y) || a.x < xMin || a.x > xMax) continue;
    const px = X(a.x), py = Y(a.y), cor = a.lado === "esquerda" ? cores.esquerda : cores.direita;
    ctx.beginPath(); ctx.arc(px, py, 7, 0, Math.PI * 2); ctx.fillStyle = cor; ctx.fill();
    ctx.lineWidth = 2.5; ctx.strokeStyle = cores.fundo; ctx.stroke();
    etiqueta(ctx, `${fmt3(a.y)}`, px + (a.lado === "esquerda" ? -12 : 12), py - 16, a.lado === "esquerda" ? "right" : "left", cor, fonte);
  }

  if (alcas && area) {
    for (const xb of [area.a, area.b]) {
      if (xb < xMin || xb > xMax) continue;
      const px = X(xb), py = base;
      ctx.fillStyle = cores.fundo; ctx.strokeStyle = cores.curva; ctx.lineWidth = 2;
      redondo(ctx, px - 7, py - 13, 14, 26, 6); ctx.fill(); ctx.stroke();
      ctx.strokeStyle = cores.curva; ctx.lineWidth = 1.2; ctx.beginPath();
      ctx.moveTo(px - 2, py - 5); ctx.lineTo(px - 2, py + 5); ctx.moveTo(px + 2, py - 5); ctx.lineTo(px + 2, py + 5); ctx.stroke();
    }
  }

  if (mira && mira.x >= xMin && mira.x <= xMax) {
    const y = f(mira.x);
    if (Number.isFinite(y)) {
      const px = X(mira.x), py = Y(y);
      ctx.strokeStyle = cores.mira; ctx.lineWidth = 1; ctx.setLineDash([3, 4]);
      ctx.beginPath(); ctx.moveTo(px, pad.t); ctx.lineTo(px, pad.t + h); ctx.stroke(); ctx.setLineDash([]);
      ctx.beginPath(); ctx.arc(px, py, 4.5, 0, Math.PI * 2); ctx.fillStyle = cores.curva; ctx.fill();
      etiqueta(ctx, `(${fmt3(mira.x)}; ${fmt3(y)})`, px + (px > pad.l + w * 0.7 ? -12 : 12), py - 18, px > pad.l + w * 0.7 ? "right" : "left", cores.ponto, fonte);
    }
  }
}

function redondo(ctx, x, y, w, h, r) {
  ctx.beginPath(); ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
  ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
}

  ctx.fillStyle = "#ffffff"; ctx.textAlign = "left"; ctx.textBaseline = "middle"; ctx.fillText(texto, x0 + 7, y + 0.5);
}

/** Lê um número digitado ("2,5", "-3", " 10 ") e confere o intervalo permitido. */
export function lerNumero(texto, { min = -1000, max = 1000, nome = "o valor" } = {}) {
  const limpo = String(texto ?? "").trim().replace(/\s/g, "").replace("−", "-").replace(",", ".");
  if (limpo === "") return { ok: false, erro: `Digite ${nome}.` };
  if (!/^[-+]?(\d+\.?\d*|\.\d+)$/.test(limpo)) return { ok: false, erro: `${cap(nome)} precisa ser um número.` };
  const valor = Number(limpo);
  if (valor < min || valor > max) return { ok: false, erro: `Use ${nome} entre ${formatNumber(min)} e ${formatNumber(max)}.` };
  return { ok: true, valor };
}

  },

/** Derivada em x0: valor exato pela regra, conferência numérica e reta tangente. */
export function calcularDerivada(regra, x0) {
  const d = DERIVADAS[regra];
  const erro = d.proibido?.(x0);
  if (erro) return { ok: false, erro };
  const y0 = d.f(x0), inclinacao = d.df(x0), h = 1e-4;
  const numerica = (d.f(x0 + h) - d.f(x0 - h)) / (2 * h);
  return { ok: true, y0, inclinacao, numerica, tangente: (x) => y0 + inclinacao * (x - x0) };
}

/** Regra de Simpson (n par), usada só para conferir o resultado exato. */
export function simpson(f, a, b, n = 200) {
  const h = (b - a) / n;
  let s = f(a) + f(b);
  for (let i = 1; i < n; i += 1) s += f(a + i * h) * (i % 2 ? 4 : 2);
  return (s * h) / 3;
}

export function calcularIntegral(tipo, a, b) {
  const I = INTEGRAIS[tipo];
  if (a === b) return { ok: true, valor: 0, numerica: 0 };
  return { ok: true, valor: I.F(b) - I.F(a), numerica: simpson(I.f, a, b) };
}
